# 07 非機能要件定義書（IPA 非機能要求グレード2018 参考）

文書ID: NFR-001｜版: 0.1.0｜状態: 指標は提案値・未承認

## 1. 評価方針
IPA 非機能要求グレード2018 の 6 主要領域（可用性、性能・拡張性、運用・保守性、移行性、セキュリティ、システム環境・エコロジー）を用いて、V1 の**測定予定値**を定める。IPA の正式グレード値をそのまま転記したものではなく、案件固有の暫定要求である。

| ID | 領域 | 提案目標 | 検証 | 現状 |
|---|---|---|---|---|
| REQ-N001 | 可用性 | 再起動後にコミット済み単発書込みを再生 | ST-001/002, fault injection | 実装あり / 未実測 |
| REQ-N002 | データ保全 | WAL 破損時にサイレント継続せず起動失敗 | ST-001 | 実装あり / 未実測 |
| REQ-N003 | 性能 | 1万件 Put/Get の p95 と throughput を計測・記録 | ST-P001 | 未実施 |
| REQ-N004 | 拡張性 | テストで 10万 records の起動時間と peak RSS を計測 | ST-P002 | 未実施 |
| REQ-N005 | 保守性 | REQ→コード→試験 ID の追跡率 100% (V1 Must) | QA-TRACE | 静的レビュー必要 |
| REQ-N006 | 移行性 | engine 差替前に同一 storage ID + protocol/model 検証 | IT-001/002 | 実装あり / 未実測 |
| REQ-N007 | セキュリティ | V1 は loopback API すら提供せずローカル限定 | code review | 実装上ネットワークなし |
| REQ-N008 | 改ざん検知 | 各 WAL entry CRC32 | unit test / ST | 実装あり / 未実測 |
| REQ-N009 | ログ | CLI 異常は stderr と非ゼロ終了 | manual ST | 実装あり / 未実測 |

| REQ-N011 | 復旧 | 破損時はバックアップからの手動復帰手順を提供 | DR drill | 手順のみ |
| REQ-N012 | 環境 | core 本体の実行時外部 crate 依存はゼロ | Cargo.toml inspect | 実装あり |

## 2. SLI/SLO の非保証
p95、RPO、RTO、throughput の数値はテスト機器、データ分布、fsync/OS 条件で変動するため未測定の性能値は約束しない。V1 は可用性 SLA の対象外。

## 3. 受入環境
OS: Linux + Windows 11。Rust: stable。ストレージ: ローカル SSD、単一 process writer。プロセス終了/電源断模擬、正常系・異常系・境界系を別々に実施する。Turso Worker は crate version 0.8.3 をピン留めし、更新時は再評価。
