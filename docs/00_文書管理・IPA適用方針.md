## 1. 適用基準と適合性の位置付け
本パッケージは IPA「共通フレーム2013」のライフサイクルプロセス、IPA「ユーザのための要件定義ガイド 第2版」、IPA「非機能要求グレード2018」の考え方を**参考に独自作成**した成果物セットである。IPA 認証・監修・公式書式・規格適合証明を意味しない。「共通フレーム」は作業プロセスの枠組みであり、全案件に単一固定の成果物書式を強制するものではない。JIS/ISO への正式適合性判定には原典、適用範囲、監査証跡、関係者の承認が必要。

## 3. 変更管理
- 変更要求には CR-ID、発案日、変更理由、対象要件、影響設計、影響テスト、承認者、結果を付す。
- 要件定義を唯一の機能スコープ基準とする。実装者による無承認の仕様追加は禁止する。
- V1 で未実装の内容は文書に「計画」「未実施」と明記する。
- レビュー判定: 承認 / 条件付承認 / 差戻し。現版は「未承認」。
