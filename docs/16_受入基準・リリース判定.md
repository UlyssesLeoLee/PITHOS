## 1. 必須証跡
1. 設計と REQ の承認印（承認者/日付/版）。
2. `cargo fmt`、`cargo clippy`、`cargo test`、`cargo build --release` の実行ログ。
3. UT/IT/ST それぞれの case ID に対する pass/fail evidence。
4. Windows 11 / Linux 双方の実機結果（V1 対象）。
5. 故障時復元（backup/restore）とデータ破損 fail-closed の手動確認。
6. Third-party dependency / OSS license と未修正リスクの承認。

## 3. Go/No-Go
既知の高リスク（プロセス間ファイル競合、SQL 生文字列、Worker timeout 不在、署名/権限なし）が存在するため、**V1 は研究・社内ローカル検証用途のみ**。本番機密情報、Web 公開、SQLite 互換システム代替への Go 判定は不可。
