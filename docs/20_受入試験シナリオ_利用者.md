# 20 利用者受入テスト（UAT）

文書ID: UAT-001｜版: 0.1.0｜状態: 未実施

| ID | 業務シナリオ | 操作 | 判定基準 |
|---|---|---|---|
| UAT-001 | ローカルドキュメントを保存 | Document Put→Get | byte-for-byte 同一 |
| UAT-002 | 運用を止めず Worker の論理切替 | デモで 2 manifest を同一 dataset に向ける | generation 進行、検証一致 |
| UAT-003 | 悪い候補の自動切戻し | 違う dataset/plugin を指定 | 旧値保持、切替拒否 |
| UAT-004 | 疑似障害後の復元確認 | 正常バックアップを別 dir に戻す | 複数サンプル一致 |
| UAT-005 | SQL 関係型の最小試験 | Turso worker CREATE/INSERT/SELECT | 手動で行数一致 |

**合格条件**: 関係者がデータ重要度・未実装範囲・障害時の責任分界に合意し、結果ログを保存すること。ベンチマークが未測定であれば性能の合格は宣言しない。
