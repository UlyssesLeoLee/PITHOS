# 01 要件定義書（システム・ソフトウェア要件）

文書ID: REQ-001｜版: 0.1.0｜状態: 未承認｜対象: ローカル実行 V1 + 将来ロードマップ

## 1. 背景・目的
SQLite 級の組込容易性を起点に、Rust 製の**多モデルデータベース基盤**を構築する。関係型は初期 Turso アダプタで提供し、後日独自 SQL/ストレージエンジンへ段階移行する。非関係型（KV/Document/Graph/Vector）は型別プラグインとし、実行中の安全な切替を基本方針とする。

## 2. ステークホルダーと利用シナリオ
| アクター | 目的 | 権限境界 |
|---|---|---|
| アプリ開発者 | KV/Document/SQL の統一 API を利用 | ローカル CLI（V1） |
| プラグイン作者 | 独立プラグインを供給 | 承認済み実行ファイルのみ |
| 運用者 | 登録、切替、障害回復 | 管理者アクセス |
| 将来の AI Agent | 検索・索引・イベント購読 | V2 以降の認可基盤必須 |

## 3. 対象範囲
**V1 実装**: Rust 微内核、KV/Document 保存・照会・削除・prefix scan、WAL チェックサム、再起動読込、プラグイン登録、同一データセットの排空式 hot swap、プロセス型 Worker、IPC v1、ローカル manifest、CLI、テストコード。
**V1 試験的**: Turso 0.8.3 SQL worker ソース（別ビルド、依存取得が必要）。SQL の生文字列は信頼できるローカル管理用途に限る。
**非対象 / 将来**: MVCC/完全 ACID、分散トランザクション、Graph/Vector 実行、SQL 最適化、ユーザー認証、ネットワーク公開、暗号化、オンラインデータ移行、バックアップ管理、WASM 実行、.NEMA 構文解析、本番 SLA。説明をもって実装完了とみなさない。

## 5. 制約
- 初期利用者はローカル単一プロセスで、信頼できる管理者のみとする。WAL は OS プロセス間ロックを持たず、**同一ファイルへの複数プロセス同時書込み禁止**。
- 任意プラグインの無条件 hot unload は要求しない。WAL の format migration も V1 対象外。
- データ損傷時は自動修復しない。エラーを返しバックアップから復旧する。
- `document` は不透明バイト列の保存モデルであり、JSON Schema・二次索引未対応。
- 全モデル間の ACID を初期段階で保証しない。Turso 自体の機能を PolyDB 全体の保証と混同しない。

## 6. 受入条件
V1 判定は `cargo test --all-targets` 成功、必須テスト `UT-001..004, IT-001..004, ST-001..003` 実行結果、設計レビュー、リスク認識の承認、環境差異検証、再起動・破損データ試験に基づく。Turso Worker は別評価項目とし、未検証で V1「正式可用」とは判定しない。
