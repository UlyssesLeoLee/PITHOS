# PITHOS DB Logo Assets

Source: the user's selected minimal open-lid, smoke, red/gold comic-style PITHOS DB logo.

## Contents
- PNG_Transparent/: 18 square RGBA PNG files, 16–2048 px.
- WEBP_Transparent/: web-friendly transparent versions.
- PITHOS_DB.ico: multi-resolution Windows/favicons (16, 24, 32, 48, 64, 128, 256).
- PITHOS_DB_Master_1254.png: transparency-extracted RGBA image at original source size.
- Original_Reference_RGB_1254.png: exact original artwork; the visible checkerboard is baked into its RGB pixels.
- Preview_Dark_Background.png: verification preview for dark backgrounds.

## Notes
- A real alpha channel was extracted from the reference; it did not originally have one. Some very pale lighting pixels may be approximate due to the baked checker pattern.
- 2048 PNG is an upscaled export, not native 2048-resolution artwork.
- For websites, 128/256/512 PNGs or WebPs are recommended; for Windows app, use the ICO.
- Small-size exports preserve the full wordmark but text legibility at 16–32 px is limited by the complex original emblem.
